# tangoAW2: five armies. Every patch the 5-army Versus map needs, applied to
# the ROM image in memory only while that map is being played (and removed
# otherwise, so every other game runs the untouched code).
#
# Unit ids are one byte. The game gives army a the ids (a-1)*64 + 1..50 and
# recovers the army with id >> 6. For five armies tangoAW2 gives army a the
# ids (a-1)*51 + 1..50 (1..254 in all) and replaces each place that encodes or
# decodes the army. A0(x) = x / 51 (0-based army of an id or block base),
# B(x) = A0(x) * 51, S(x) = x - B(x).
#
# Lines (| then the original instruction, checked against the ROM):
#   imm  ADDR NEW              new immediate for cmp/movs/adds/subs
#   hook ADDR KIND DST SRC     replace the instruction: DST = KIND(SRC)
#   fn   ADDR NAME             replace the whole function (entry)
#   pre  ADDR NAME             run NAME, then the instruction
#   word ADDR TABLE            literal word -> tangoAW2's table (old value checked)
#   half ADDR OLD NEW          raw halfword
